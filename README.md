# TinyGFX
A simple graphics library implemented for TinyGO Drivers

# Features
* Implements basic Shape drawing functions.
* Leverages TinyFont library for drawing text onto the screen.
* Implements bitmap decoding of images to draw a black and white image on the screen.
* Implements various 90 degree spaced orientation settings.
* Can modify the behaviour functions by changing the library constants.
* Packs all the features in a nice single data structure layout for ease of use.
